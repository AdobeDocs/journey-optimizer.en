+++ AI Knowledge Reference

This section contains structured knowledge intended to support interpretation, retrieval, and question answering related to this topic.

Neither source is intended to stand alone; the page describes the feature, while this section provides additional context that helps disambiguate terminology, intent, applicability, and constraints.

* **TL;DR:** This page walks through the key steps to build and launch an Orchestrated campaign in Adobe Journey Optimizer, from creation and scheduling to orchestrating activities, adding personalization, monitoring execution, reporting, and retargeting.

**Intents:**

* Create and schedule an Orchestrated campaign, as a one-time push or a recurring multi-channel campaign.
* Orchestrate campaign activities by combining targeting, delivery, and flow control activities on a visual canvas.
* Add personalization in channel activities using profile attributes and target attributes from the worktable, including enrichment collection arrays.
* Run a campaign in test mode to catch issues before publishing, then monitor live execution in real time.
* Analyze campaign results using built-in reports and real-time dashboards.
* Retarget profiles after a campaign has run, based on how they interacted with the message (such as opening it or clicking a link).

**Glossary:**

* **Orchestrated campaign** *(product-specific)*: the campaign type covered by this page's steps, created and scheduled, then designed with activities on a visual canvas.
* **Worktable** *(product-specific)*: the source of target attributes, including enrichment collection arrays, used for personalization in channel activities.

**FAQ:**

* **Q: What is the first step in building an Orchestrated campaign?** — Create and schedule the campaign, defining when it should run, whether as a one-time push or a recurring multi-channel campaign.
* **Q: How do you design the logic of a campaign?** — Using a visual canvas, you combine targeting, delivery, and flow control activities to shape the customer experience.
* **Q: Where can personalization be added?** — In channel activities, using profile attributes and target attributes from the worktable, including enrichment collection arrays.
* **Q: What should be done before publishing a campaign?** — Run it in test mode first to catch any issues, then publish it and monitor live execution in real time.
* **Q: What can be done after a campaign has run?** — Retarget profiles based on how they interacted with the message, such as whether they opened it or clicked a link, to follow up with tailored messages, re-engage inactive users, or double down on interest.
