* **TL;DR:** This page explains how to access and use the rule builder to filter data and build the queries that target audiences in Orchestrated campaigns.

**Intents:**

* Identify the contexts where the rule builder is available.
* Specify a target population using a Build audience activity.
* Apply a condition in the campaign canvas using a Split activity.
* Build advanced filters for lists such as campaign logs or targeting dimensions.
* Understand the central canvas and the Rule properties pane in the rule builder interface.
* Reuse saved queries through predefined filters.

**Glossary:**

* **Rule builder**: a tool that simplifies filtering the database based on various criteria, manages complex and long queries, and supports predefined filters within conditions *(product-specific)*
* **Central canvas**: the part of the rule builder interface where components are added and combined to build a rule *(product-specific)*
* **Rule properties pane**: the pane that provides information on the rule and allows operations to check the rule and ensure it suits the user's needs; it displays when building a query to create an audience *(product-specific)*
* **Build audience activity**: used to specify the population to target in an Orchestrated campaign by creating new audiences *(product-specific)*
* **Split activity**: used to apply rules within the campaign canvas *(product-specific)*
* **Predefined filters**: saved queries, including versions with parameters, that can be reused in the rule builder *(product-specific)*

**FAQ:**

* **Q: Where is the rule builder available?** — In every context where rules are needed to filter data, including building audiences with a Build audience activity, applying conditions in the campaign canvas with a Split activity, and building advanced filters for lists such as campaign logs or targeting dimensions.
* **Q: What does the rule builder interface consist of?** — A central canvas where components are added and combined to build the rule, and a Rule properties pane that provides information on the rule and lets the user check it.
* **Q: When does the Rule properties pane display?** — When building a query to create an audience.
* **Q: Can saved queries be reused in the rule builder?** — Yes, through predefined filters, including versions with parameters.
