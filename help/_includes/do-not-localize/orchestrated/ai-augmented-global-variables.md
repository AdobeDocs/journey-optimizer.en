* **TL;DR:** This page explains how to add and manage global variables on an Orchestrated campaign so shared name-value pairs can be reused across the rule builder, Test conditions, and other canvas logic.

**Intents:**

* Open the variables panel for an Orchestrated campaign.
* Add a new global variable with a name and value.
* Edit an existing global variable.
* Understand that global variables are defined per campaign for reuse across canvas logic.

**Glossary:**

* **Global variable**: a name-value pair set on a single Orchestrated campaign and reused on each run to steer Test conditions, the rule builder, and other canvas logic *(product-specific)*
* **Edit variables**: the menu option, accessed from the **...** icon next to **Save**, used to open the variables panel *(product-specific)*
* **Add variable**: the control used to create a new global variable by setting its name and value *(product-specific)*

**Guardrails:**

* none

**Terminology:**

* Canonical name: global variable — variants: variable

**FAQ:**

* **Q: What is a global variable in an Orchestrated campaign?** — A name-value pair set on a single Orchestrated campaign and reused on each run to steer Test conditions, the rule builder, and other canvas logic.
* **Q: How do I add a global variable?** — Open the Orchestrated campaign, click the **...** icon next to **Save**, select **Edit variables**, then click **Add variable** and set its name and value.
* **Q: How do I edit an existing global variable?** — In the variables panel, click the **...** button next to the variable and select **Edit**.
* **Q: Where are global variables used once defined?** — In rules and Test conditions on the campaign canvas.
