+++ AI Knowledge Reference

* **TL;DR:** This page explains how to monitor live web experiences in Journey Optimizer by checking the web reports and setting up click tracking on specific page elements.

**Intents:**

* Check the Web tab of the Journey report and Campaign report for a live web experience
* Compare metrics such as impressions, click rate, and engagements
* Set up click tracking on any element of a web page from the web designer
* Add labels to tracked elements to find them in the reports
* Remove click tracking from an element
* Review the number of clicks per element once the campaign is live

**Glossary:**

* **Click tracking**: A web designer capability that tracks clicks on any selected element of a website so the number of clicks appears in the web reports *(product-specific)*
* **Click track element**: The contextual menu option used to start tracking clicks on a selected element *(product-specific)*
* **Click track pane**: The left pane where tracked actions automatically display and are managed *(product-specific)*
* **Web reports**: The Web tab of the Journey report and Campaign report showing metrics such as impressions, click rate, and engagements *(product-specific)*

**Guardrails:**

* Web reports are available once the web experience is live.
* Any item on the page, clickable or not, can be selected for click tracking.
* Add a meaningful label to each tracked element to manage them and find them easily in the reports.
* The number of clicks per element is available in the reports once the campaign is live.

**Terminology:**

* Canonical name: click tracking — Acronym: n/a — variants: click track element, Click track pane
* Synonyms: "web reports" = "Web tab of the Journey report and Campaign report"
* Do not confuse: "Click track element" (contextual menu option to track clicks) ≠ "click rate" (a metric shown in the web reports)
* Do not confuse: campaign web "live report" ≠ "Customer Journey Analytics report" (both used to check clicks per element once the campaign is live)

**FAQ:**

* **Q: Where do I check web experience performance?** — In the Web tab of the Journey report and Campaign report, once the web experience is live.
* **Q: What metrics can I compare in the web reports?** — Elements such as the number of impressions, click rate, and number of engagements with your web page.
* **Q: How do I set up click tracking?** — Select an element in the page, choose Click track element from the contextual menu, and add a meaningful label; the tracked action displays in the Click track pane.
* **Q: Can I track a non-clickable element?** — Yes, any item, clickable or not, can be selected for click tracking.
* **Q: How do I remove click tracking from an element?** — Select the corresponding delete icon.
