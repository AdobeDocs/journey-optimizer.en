# AI Knowledge Reference

+++ AI Knowledge Reference

This section contains structured knowledge intended to support interpretation, retrieval, and question answering related to this topic.

For complete understanding, this information should be combined with the documentation on this page. Neither source is intended to stand alone; the page describes the feature, while this section provides additional context that helps disambiguate terminology, intent, applicability, and constraints.

* **TL;DR:** Journey Optimizer provides accessibility features aligned with WCAG 2.1 Level A and Level AA, inherited from Adobe Experience Platform, along with keyboard shortcuts for navigating and working in the interface.

**Intents:**

* Understand which accessibility standards Journey Optimizer aligns with
* Navigate user interface elements, sections, and menu groups using the keyboard
* Use keyboard shortcuts specific to the journey canvas in draft status
* Configure activities, events, data sources, and actions using the keyboard
* Find guidance for designing accessible email and landing page content

**Glossary:**

* **WCAG 2.1**: The Web Content Accessibility Guidelines that Journey Optimizer follows at Level A and Level AA
* **Keyboard accessibility**: One of the accessibility features inherited from Adobe Experience Platform *(product-specific)*
* **Color contrast**: One of the accessibility features inherited from Adobe Experience Platform *(product-specific)*
* **Validation of required fields**: One of the accessibility features inherited from Adobe Experience Platform *(product-specific)*
* **Journey canvas in draft status**: The interface area where a specific set of keyboard shortcuts applies *(product-specific)*

**Guardrails:**

* Journey Optimizer follows the Web Content Accessibility Guidelines (WCAG) 2.1 Level A and Level AA.
* The accessibility features in Journey Optimizer are inherited from Adobe Experience Platform: keyboard accessibility, color contrast, and validation of required fields.
* Some keyboard shortcuts apply only within specific areas of the interface, such as the journey canvas in draft status, the configuration pane, text fields, pop-up windows, the simple expression editor, XDM field browsing, and payload preview.
* Guidelines for designing accessible content for emails and landing pages are covered in a separate section, not on this page.

**Terminology:**

* Canonical name: Web Content Accessibility Guidelines — Acronym: WCAG — variants: WCAG 2.1, WCAG 2.1 Level A, WCAG 2.1 Level AA
* Synonyms: "keyboard shortcut" = "shortcut"
* Do not confuse: "Tab" (move forward between elements) ≠ "Shift + Tab" (move backward between elements)
* Do not confuse: "Enter or Spacebar" (select or clear an element in focus) ≠ "Esc" (cancel a selection, collapse a pane, or close a dialog box)

**FAQ:**

* **Q: Which accessibility standards does Journey Optimizer follow?** — It follows the internationally recognized best practices in WCAG 2.1 Level A and Level AA.
* **Q: Where do the accessibility features come from?** — They are inherited from Adobe Experience Platform and include keyboard accessibility, color contrast, and validation of required fields.
* **Q: How do I delete selected activities on the journey canvas?** — On the journey canvas in draft status, press Delete or Backspace, then Enter to confirm the deletion.
* **Q: How do I discard changes in a configuration pane using the keyboard?** — Press Esc to discard changes and close the configuration pane.
* **Q: Where can I find guidance for accessible email and landing page content?** — In the accessible content section referenced from this page.
