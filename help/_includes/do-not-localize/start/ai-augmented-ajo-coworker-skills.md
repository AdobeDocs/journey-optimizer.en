# AI Knowledge Reference

+++ AI Knowledge Reference

This section contains structured knowledge intended to support interpretation, retrieval, and question answering related to this topic.

For complete understanding, this information should be combined with the documentation on this page. Neither source is intended to stand alone; the page describes the feature, while this section provides additional context that helps disambiguate terminology, intent, applicability, and constraints.

* **TL;DR:** This page describes the Journey Optimizer AI capabilities available in CX Coworker, covering the Journey skills (Journey Create, Channel Content Create, Journey Analyze), the Loyalty skills, and the Content Management MCP tools, with permissions, sample prompts, and best practices for each.

**Intents:**

* Build and configure journeys through natural language with Journey Create
* Generate, edit, and manage channel content for journeys with Channel Content Create
* Analyze journeys, detect conflicts, and diagnose issues with Journey Analyze
* Create and manage loyalty challenges and query loyalty data with the Loyalty skills
* Discover, create, update, and publish content assets with the Content Management tools
* Understand the permissions and in-scope versus out-of-scope capabilities of each skill

**Glossary:**

* **CX Coworker**: Adobe's conversational experience that integrates with business applications and brings AI-powered skills to Journey Optimizer *(product-specific)*
* **Journey Create**: A skill that builds and configures marketing journeys from natural language prompts *(product-specific)*
* **Channel Content Create**: A skill that generates, edits, and manages channel-specific content for journeys using AI-powered content generation *(product-specific)*
* **Journey Analyze**: A skill that analyzes and optimizes journeys, detecting conflicts, fallout, anomalies, and custom action errors *(product-specific)*
* **Loyalty Challenge Management**: A skill that creates and manages loyalty challenges from natural language prompts *(product-specific)*
* **Loyalty Insights Skill**: A skill that queries and analyzes loyalty program performance data using natural language *(product-specific)*
* **Content Management tools**: A set of 15 read and write-capable MCP tools to discover, create, and manage Journey Optimizer content *(product-specific)*

**Guardrails:**

* Channel Content Create is available for all customers in Limited Availability; contact your Adobe representative to gain access.
* Journey Create requires the Manage Journeys, View Journey Events, Data Sources and Actions, View Segments, and Manage Segments permissions for full use.
* Journey Analyze is available to all customers with access to CX Coworker; full use requires the View Journeys, Manage Journeys, View Segments, and Manage Segments permissions.
* Loyalty skills are available in CX Coworker for eligible organizations; customers with a Loyalty license can access the loyalty skills even without an additional CX Coworker license.
* Content Management is available for all customers with access to CX Coworker and is powered by 15 read and write-capable MCP tools.
* Journey Create does not support advanced journey analytics, cross-journey orchestration, A/B testing configuration, InAudience expression generation, dataset lookup nodes, wave sending settings, schedule recurrence options, namespace selection for audiences, custom action field mapping, or complex data transformations.
* Journey Analyze does not support automated journey creation, channels overlap, journey entry analysis, technical issue analysis, or fatigue analysis.
* Content Management does not support full-text search across templates or fragments, template or fragment validation, creating or publishing landing pages, or deleting content templates, fragments, or landing pages.
* Loyalty Challenge Management does not support challenge deletion.

**Terminology:**

* Canonical name: CX Coworker — Acronym: n/a — variants: Coworker
* Do not confuse: "Journey Create" (build journeys) ≠ "Journey Analyze" (analyze and optimize journeys) ≠ "Channel Content Create" (generate channel content)
* Do not confuse: "Loyalty Challenge Management" (create and manage challenges) ≠ "Loyalty Insights Skill" (query and analyze loyalty data)
* Do not confuse: "In scope skills" (currently supported capabilities) ≠ "Out of scope skills" (functionalities not currently supported)

**FAQ:**

* **Q: What permissions does Journey Create require?** — Manage Journeys, View Journey Events, Data Sources and Actions, View Segments, and Manage Segments.
* **Q: Is Channel Content Create generally available?** — No; it is available for all customers in Limited Availability, so contact your Adobe representative to gain access.
* **Q: Can I use the Loyalty skills without a CX Coworker license?** — Customers with a Loyalty license can access the loyalty skills even without an additional CX Coworker license.
* **Q: Does Journey Create support A/B testing configuration?** — No; A/B testing configuration is listed as currently out of scope.
* **Q: Can the Content Management tools delete content templates or fragments?** — No; deleting content templates, fragments, or landing pages is not supported.
