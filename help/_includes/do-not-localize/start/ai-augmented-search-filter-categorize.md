# AI Knowledge Reference

+++ AI Knowledge Reference

This section contains structured knowledge intended to support interpretation, retrieval, and question answering related to this topic.

For complete understanding, this information should be combined with the documentation on this page. Neither source is intended to stand alone; the page describes the feature, while this section provides additional context that helps disambiguate terminology, intent, applicability, and constraints.

* **TL;DR:** This page explains how to locate and organize Journey Optimizer objects using unified search, list filters, bulk actions, and Unified tags.

**Intents:**

* Find assets, journeys, datasets, and more across sandboxes with unified search
* Filter and sort lists by type, status, creator, or modification date
* Apply bulk actions to multiple selected items at once
* Classify objects with Unified tags and filter lists by tag
* Manage and organize tags by category as an administrator

**Glossary:**

* **Unified search**: The Adobe CX Enterprise search capability on the center of the top bar, used to find assets, journeys, datasets, and more across your sandboxes; help articles about the entered keywords also appear in the results *(product-specific)*
* **Unified tags**: Adobe Experience Platform Unified Tags used to classify Journey Optimizer objects and improve search from the lists *(product-specific)*
* **Bulk action bar**: A bar that appears at the bottom of the screen when multiple items are selected, letting you apply operations to all of them *(product-specific)*
* **Uncategorized**: The built-in category to which tags created directly from the Tags field in Journey Optimizer are automatically added *(product-specific)*

**Guardrails:**

* Unified tags are available for filtering lists for journeys and campaigns for now.
* The Tags field is available for the following objects: Campaigns, Decision items, Fragments, Journey Fragments, Journeys, Landing pages, Subscription lists, Templates, and Channel configurations.
* Bulk actions are available in the Campaigns, Fragments, Journeys, and Templates lists.
* Archive is available for Fragments and Templates; Delete is available for Campaigns and Journeys; bulk Pause and Resume are available for Journeys.
* Only administrators can delete tags and organize them by categories, using the Tags menu under ADMINISTRATION.
* Tags are not case-sensitive.
* Column personalization is saved for each user.

**Terminology:**

* Canonical name: Unified tags — Acronym: n/a — variants: tags, Adobe Experience Platform Unified Tags
* Synonyms: "unified search" = "Adobe CX Enterprise search capability"
* Do not confuse: "Move to folder" (moves selected items into a folder) ≠ "Add to package" (exports selected items to another sandbox)

**FAQ:**

* **Q: What can I find with unified search?** — Assets, journeys, datasets, and more across your sandboxes; help articles about the entered keywords also appear, and pressing Enter shows all results with filtering by business object.
* **Q: Which objects can I tag?** — Campaigns, Decision items, Fragments, Journey Fragments, Journeys, Landing pages, Subscription lists, Templates, and Channel configurations.
* **Q: Which lists support bulk actions, and which operations are available?** — The Campaigns, Fragments, Journeys, and Templates lists support bulk actions including Add to package, Move to folder, Edit tags, Manage access, Archive (Fragments and Templates), and Delete (Campaigns and Journeys); Journeys also support bulk Pause and Resume.
* **Q: Are tags case-sensitive?** — No. Tags are not case-sensitive.
* **Q: Who can delete or organize tags?** — Administrators can delete tags and organize them by categories using the Tags menu under ADMINISTRATION.
* **Q: Are tags kept when I duplicate an object or create a new version?** — Yes. If you duplicate or create a new version of an object, tags are preserved.
