# AI Knowledge Reference

+++ AI Knowledge Reference

This section contains structured knowledge intended to support interpretation, retrieval, and question answering related to this topic.

For complete understanding, this information should be combined with the documentation on this page. Neither source is intended to stand alone; the page describes the feature, while this section provides additional context that helps disambiguate terminology, intent, applicability, and constraints.

* **TL;DR:** This page explains the redesigned **[!UICONTROL Simulate content variations]** experience, where all content variants render together in a scrollable side-by-side grid managed from a single bottom action bar, with options to create variants manually, from a file, with AI, or from simulated users.

**Intents:**

* Open the content simulation screen by clicking **[!UICONTROL Simulate content]**
* Create variants manually, by uploading a CSV, JSON, or JSONLINES file, by AI generation, or from simulated users
* Preview and edit variants, change the layout, and switch between desktop and mobile views from the bottom action bar
* Export current variants to a CSV file
* Use Email-specific tools: **[!UICONTROL Spam report]**, **[!UICONTROL Render email]**, **[!UICONTROL Send proof]**, **[!UICONTROL View configuration details]**
* Switch back to the classic experience at any time

**Glossary:**

* **[!UICONTROL Simulate content variations]**: The redesigned experience that renders all content variants together in a single scrollable grid controlled from a bottom action bar. *(product-specific)*
* **Variant**: A version of the content with different attribute values, created manually, by file upload, with AI, or from a simulated user. *(product-specific)*
* **Simulated users**: Reusable, profile-like test entities that are saved across sessions and can be shared with other users; unlike manually entered variants, they persist beyond the current browser session. *(product-specific)*
* **[!UICONTROL Generate]**: The bottom-action-bar button that auto-generates variants with AI; clicking it replaces all existing variants. *(product-specific)*
* **[!UICONTROL Send proof]**: An Email-channel tool that sends a proof of one or more variants to a set of email recipients. *(product-specific)*

**Guardrails:**

* You can add up to 30 variants manually or via file upload.
* When using AI generation, up to 40 variants can be created depending on your content's complexity.
* Clicking **[!UICONTROL Generate]** replaces all existing variants, including any added manually or from a file.
* Editing a simulated-user variant's attribute values is local to testing and is not saved back to the simulated user record.
* **[!UICONTROL Send proof]** accepts up to 10 recipient addresses.

**Terminology:**

* Canonical name: Simulate content variations — variants: content variations, content variants
* Do not confuse: "[!UICONTROL Simulate content]" (the button that opens the simulation screen) ≠ "[!UICONTROL Simulate content variations]" (the experience) ≠ "[!UICONTROL Switch to classic experience]" (returns to the classic layout)
* Do not confuse: "[!UICONTROL Preview]" (view rendering) ≠ "[!UICONTROL Edit]" (edit content and attribute values)
* Do not confuse: variants added for the current session ≠ "simulated users" (saved, reusable across sessions)
* Do not confuse: "[!UICONTROL Send proof]" (send variant proofs to email recipients) ≠ "[!UICONTROL Render email]" (preview across email clients and devices) ≠ "[!UICONTROL Spam report]" (deliverability score)

**FAQ:**

* **Q: How do I open the new experience?** — From your content, click **[!UICONTROL Simulate content]** to open the content simulation screen.
* **Q: How many variants can I add?** — Up to 30 manually or via file upload; AI generation can create up to 40 depending on your content's complexity.
* **Q: Does clicking Generate keep my existing variants?** — No. Clicking **[!UICONTROL Generate]** replaces all existing variants, including any added manually or from a file.
* **Q: How many recipients can I send a proof to?** — Up to 10 recipient addresses per proof (Email channel).
* **Q: Do simulated users persist between sessions?** — Yes. Simulated users are saved across sessions and can be shared; manually entered variants do not persist.
* **Q: How do I go back to the old layout?** — Click **[!UICONTROL Switch to classic experience]** in the bottom action bar.
