* **TL;DR:** This page explains how to design Web In-app message content in Journey Optimizer, including choosing a message layout and configuring media, text, buttons, close button, and advanced formatting options across the Content and Settings tabs.

**Intents:**

* Open the message content editor from the Edit content button in the campaign Action menu
* Choose a message layout: Fullscreen, Modal, Banner, or Custom
* Import or compose raw HTML for a Custom message
* Configure the Close button style, media, Header and Body text, and action buttons in the Content tab
* Set the background image, UI takeover, and preview the message in the Settings tab
* Enable Advanced formatting to access additional styling options

**Glossary:**

* **Message Layout**: The section where you select one of four layout options (Fullscreen, Modal, Banner, Custom) depending on your messaging needs *(product-specific)*
* **Fullscreen**: A layout that covers the entire screen of audience devices and supports media (image, video), text, and button components *(product-specific)*
* **Modal**: A layout that appears in a large alert-style window with the application still visible in the background; supports media (image, video), text, and button components *(product-specific)*
* **Banner**: A layout that appears as a native OS alert message and supports only a Header and a Body *(product-specific)*
* **Custom**: A message mode that lets you import and edit a pre-configured HTML message, using Compose to enter raw HTML or Import to import an HTML or .zip file *(product-specific)*
* **Advanced formatting**: A toggle/mode that activates additional options to customize the experience *(product-specific)*
* **UI takeover**: A Message option, enabled by default, that darkens the background behind the In-app message to emphasize the content *(product-specific)*
* **Interact event**: A button setting that defines the button's action after a user interacts with it *(product-specific)*

**Guardrails:**

* Advanced formatting options are available only when the Advanced formatting mode is switched on.
* The Banner layout supports only a Header and a Body.
* Custom messages require a pre-configured HTML message, entered via Compose (raw HTML) or brought in via Import (HTML or .zip file).
* The UI takeover option is enabled by default.

**Terminology:**

* Canonical name: Web In-app content — Acronym: n/a — variants: Web In-app message content, In-app message content
* Synonyms: "Advanced formatting" = "Advanced formatting mode"
* Do not confuse: "Content tab" (define content, Close button style, media, and buttons) ≠ "Settings tab" (define message layout, background, UI takeover, and preview)
* Do not confuse: "Header" and "Body" (message text fields) ≠ "Close button" (dismiss control with its own style options)

**FAQ:**

* **Q: How do I open the content editor?** — Click the Edit content button from the Action menu of your campaign.
* **Q: What layout options are available?** — Fullscreen, Modal, Banner, and Custom.
* **Q: Which components does the Banner layout support?** — Only a Header and a Body.
* **Q: How do I use my own HTML?** — Choose the Custom layout, then Compose to enter or paste raw HTML, or Import to import an HTML or .zip file.
* **Q: How do I get additional styling options?** — Switch on the Advanced formatting mode to access options such as fonts, sizes, colors, alignment, sizing, and position.
* **Q: What does UI takeover do?** — Enabled by default, it darkens the background behind your In-app message to emphasize the focus on your content.
