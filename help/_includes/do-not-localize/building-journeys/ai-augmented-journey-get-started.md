* **TL;DR:** This is the comprehensive getting-started guide for journey orchestration in Adobe Journey Optimizer, covering key capabilities (real-time and batch delivery, contextual data, built-in and custom actions, the visual designer, Journey Fragments, and testing), common use cases, and links to learning resources.

**Intents:**
* Understand the key capabilities available in the Journey Optimizer journey designer before building a first journey

* Discover how Journey Fragments enable reuse of common node logic across journeys
* Access video tutorials and guides for common journey use cases such as welcoming new subscribers and send-time optimization

**Glossary:**
* **Journey designer**: The drag-and-drop visual canvas in Adobe Journey Optimizer used to build and orchestrate multi-step customer journeys *(product-specific)*
* **Journey Fragment**: A reusable set of journey nodes (e.g., eligibility check, channel routing logic) built once and inserted into multiple journeys *(product-specific)*
* **Unitary delivery**: A real-time message triggered for a single profile when a specific event occurs *(product-specific)*
* **Batch delivery**: Delivery in batch using Adobe Experience Platform audiences *(product-specific)*
* **Send-time optimization**: An AI-powered feature to deliver emails when each customer is most likely to engage *(product-specific)*
* **Custom action**: Connects to a third-party system to send messages or to external APIs *(product-specific)*

**Guardrails:**
* Journey configuration must be validated and errors resolved before testing and publication.

**Terminology:**
* Canonical name: Journey orchestration
* Do not confuse: "built-in channel actions" ≠ "custom actions" — built-in actions send messages designed in Journey Optimizer; custom actions integrate third-party systems into journeys

**FAQ:**
* **Q: What is the difference between real-time (unitary) delivery and batch delivery in journeys?** — Unitary delivery is triggered when an event is received. Batch delivery uses Adobe Experience Platform audiences.
* **Q: Can I reuse common logic (like an eligibility check) across multiple journeys?** — Yes; build a set of journey nodes once and reuse them across journeys with Journey Fragments.
* **Q: Where do I go to create my first journey?** — Use the link under "Ready to start building?" to learn how to create and design your first journey.
* **Q: How do I send messages through a third-party system from a journey?** — Configure a custom action to call the external API, then add it as an action activity in the journey canvas.
* **Q: Where can I find answers to common journey questions?** — Visit the Journey FAQ page for answers about journey building, troubleshooting, and best practices.
