# AI Knowledge Reference

+++ AI Knowledge Reference

This section contains structured knowledge intended to support interpretation, retrieval, and question answering related to this topic.

For complete understanding, this information should be combined with the documentation on this page. Neither source is intended to stand alone; the page describes the feature, while this section provides additional context that helps disambiguate terminology, intent, applicability, and constraints.

* **TL;DR:** This page explains how to use the Optimize for AI Inbox capability in the Email Designer to generate and refine a dedicated version of an email so AI-assisted inbox experiences ground their summaries and answers in your offers and calls to action.

**Intents:**

* Generate a dedicated version of an email optimized for AI-assisted inbox experiences
* Refine the generated version manually before confirming it
* Re-optimize or remove the optimization for an email
* Understand the risks and limitations of third-party inbox AI
* Keep the optimized version consistent after editing the original HTML content

**Glossary:**

* **Optimize for AI Inbox**: The Email Designer button/control that generates an improved, dedicated version of the email highlighting key information for AI-assisted reading and summarization *(product-specific)*
* **AI Inbox Optimizer window**: The window where the generated optimized version is displayed *(product-specific)*
* **AI-assisted inbox experiences**: Inbox clients such as Apple Intelligence and Google Gemini in Gmail that answer questions and summarize mail based on message content *(product-specific)*

**Guardrails:**

* To access this feature, you must agree to a user agreement that displays the first time you use Generative AI in Journey Optimizer.
* The capability only generates a dedicated version in Journey Optimizer; it does not control or guarantee how a third-party assistant interprets or displays the message.
* The optimized version is different from the HTML and text views; it does not change your design, layout, or images.
* If you make changes to the original HTML content, you must re-optimize the generated version so it stays consistent with the new content.
* Once a message is delivered, AI features in third-party clients (Gmail, Apple Mail, Outlook, others) operate under those providers' terms, models, and policies — summaries can omit offers, misstate prices or dates, merge content with unrelated web results, or paraphrase away from your approved copy.
* Always review generated content before send.

**Terminology:**

* Canonical name: Optimize email for AI inboxes — Acronym: n/a — variants: Optimize for AI Inbox, AI Inbox Optimizer
* Synonyms: "Optimize for AI Inbox" = "Optimize email for AI inboxes"
* Do not confuse: "Optimize for AI Inbox" (authoring-time control in the Email Designer) ≠ end-user inbox AI assistants (third-party features that run after delivery)

**FAQ:**

* **Q: What does the Optimize for AI Inbox button do?** — It generates an improved, dedicated version of the email that highlights key information for AI-assisted reading and summarization.
* **Q: Does optimizing change my email design?** — No; the optimized version is different from the HTML and text views and does not change your design, layout, or images.
* **Q: Can I edit the automatically generated version?** — Yes; select the Enable edit toggle to make manual changes, then click Optimize Email to confirm, or use Re-optimize to generate a new version.
* **Q: What happens if I change the original HTML after optimizing?** — You need to re-optimize the generated version so it is consistent with the new content.
* **Q: Does this guarantee how an inbox assistant will present my email?** — No; behaviors depend on the inbox provider and model version, and answers or summaries from external AI clients can be wrong, incomplete, or mixed with web results.
