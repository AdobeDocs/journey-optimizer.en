# AI Knowledge Reference

+++ AI Knowledge Reference

This section contains structured knowledge intended to support interpretation, retrieval, and question answering related to this topic.

For complete understanding, this information should be combined with the documentation on this page. Neither source is intended to stand alone; the page describes the feature, while this section provides additional context that helps disambiguate terminology, intent, applicability, and constraints.

* **TL;DR:** This page explains how to set email metadata in the Email Designer — the preheader, document title, and document language — to improve the readability and accessibility of your email content.

**Intents:**

* Define a preheader that follows the subject line in the recipient's email client
* Set a document title to provide descriptive information about the email content
* Set a document language so screen readers use the correct language
* Personalize metadata fields from profile attributes, audiences, contextual attributes, and more
* Improve the readability and accessibility of email content

**Glossary:**

* **[!UICONTROL Preheader]**: A short summary text that follows the subject line when viewing an email from your email client, typically one sentence long *(product-specific)*
* **[!UICONTROL Document title]**: A field corresponding to the `<title>` element that provides descriptive information about the email, typically displayed as a tooltip on mouse hover *(product-specific)*
* **[!UICONTROL Document language]**: A setting corresponding to the `lang` attribute in the `<html>` element that specifies the language screen readers use to convert text and images into speech or braille *(product-specific)*

**Guardrails:**

* Preheaders are not supported by all email clients; when not supported, the preheader does not display.
* You must add at least a Structure component before you can start designing the email and configure these settings.
* Metadata is configured from the Body settings, accessed via the Navigation tree or the top of the right pane, on the Settings tab.

**Terminology:**

* Canonical name: email metadata — Acronym: n/a — variants: meta attributes, email content metadata
* Synonyms: "[!UICONTROL Document title]" = "`<title>` element"; "[!UICONTROL Document language]" = "`lang` attribute"
* Do not confuse: "[!UICONTROL Preheader]" (summary text after the subject line) ≠ "[!UICONTROL Document title]" (`<title>` element shown as a tooltip)

**FAQ:**

* **Q: What is a preheader?** — A short summary text that follows the subject line when viewing an email from your email client, typically one sentence long.
* **Q: Why might a preheader not display?** — Preheaders are not supported by all email clients; when not supported, the preheader does not display.
* **Q: What does the document language setting do?** — It specifies the language that screen readers use to convert text and images into speech or braille, corresponding to the `lang` attribute in the `<html>` element.
* **Q: Can I personalize the metadata fields?** — Yes. Click the personalization icon next to each field to customize content from profile attributes, audiences, contextual attributes, and more.
