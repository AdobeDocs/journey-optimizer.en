* **TL;DR:** This page introduces the Query Editor, powered by Adobe Experience Platform Query Service, for writing, validating, and running interactive and non-interactive queries on customer experience data within Journey Optimizer.

**Intents:**

* Write, validate, and run queries on customer experience data in the Journey Optimizer user interface.
* Develop queries for analysis and data exploration, and run interactive queries for development purposes.
* Run non-interactive queries to populate datasets.

**Glossary:**

* **Query Editor**: an interactive tool provided by Adobe Experience Platform Query Service to write, validate, and run queries within the Journey Optimizer user interface *(product-specific)*
* **Query Service**: the Adobe Experience Platform service that powers the Query Editor
* **Interactive query**: a query run for development purposes
* **Non-interactive query**: a query run to populate datasets

**Guardrails:**

* The Query Editor is provided by Adobe Experience Platform Query Service and runs queries on customer experience data within the Journey Optimizer user interface.

**Terminology:**

* Canonical name: Query Editor — powered by: Adobe Experience Platform Query Service
* Do not confuse: "interactive query" (run for development purposes) ≠ "non-interactive query" (populates datasets)

**FAQ:**

* **Q: What is the Query Editor?** — An interactive tool provided by Query Service to write, validate, and run queries on customer experience data in the Journey Optimizer user interface.
* **Q: What kinds of queries can I run?** — Interactive queries for development purposes, and non-interactive queries to populate datasets.
* **Q: Which service powers the Query Editor?** — Adobe Experience Platform Query Service.
