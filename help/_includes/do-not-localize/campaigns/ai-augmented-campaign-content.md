# AI Knowledge Reference

+++ AI Knowledge Reference

This section contains structured knowledge intended to support interpretation, retrieval, and question answering related to this topic.

For complete understanding, this information should be combined with the documentation on this page. Neither source is intended to stand alone; the page describes the feature, while this section provides additional context that helps disambiguate terminology, intent, applicability, and constraints.

* **TL;DR:** This page explains how to open the content of an Action campaign for the channel selected, find the channel-specific content creation pages, and preview and test the content with **Simulate content**.

**Intents:**

* Open the content of the campaign from the **Content** tab or the **Edit content** button
* Find the page that explains content creation for each channel
* Preview and test content with **Simulate content**
* Preview content with test profiles using **Simulate content (AEP profiles)**
* Go back to the campaign creation screen

**Glossary:**

* **Simulate content**: Button used to preview and test content; tests content variations with sample input data or AI auto-generation. *(product-specific)*
* **Simulate content (AEP profiles)**: Option selected from the **Simulate content** dropdown; previews the content with test profiles. *(product-specific)*

**Terminology:**

* Canonical name: Action campaign content — variants: message content
* Acronym: AEP — Adobe Experience Platform
* Do not confuse: "Simulate content" (sample input data or AI auto-generation) ≠ "Simulate content (AEP profiles)" (test profiles)

**FAQ:**

* **Q: How do I open the content of my Action campaign?** — Navigate to the **Content** tab or click the **Edit content** button.
* **Q: Where do I find how to create content for my channel?** — The content creation process depends on the channel you selected; the page lists Email, Mobile message, Push notification, Direct mail, In-app, Web, Code-based experience, Content cards, LINE, and WhatsApp, each linking to its page.
* **Q: How do I preview and test my content?** — Use **Simulate content** to test content variations with sample input data or AI auto-generation, or select **Simulate content (AEP profiles)** from the dropdown to preview with test profiles.
* **Q: How do I go back to the campaign creation screen?** — Click the left arrow.
