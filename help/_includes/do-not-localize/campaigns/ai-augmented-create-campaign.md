* **TL;DR:** This page introduces Action campaigns (also called Scheduled campaigns) for simple ad-hoc batch communications and lists, in order, the six key steps to create one.

**Intents:**

* Understand what an Action campaign is and which use cases it covers
* Know the order of the steps to create an Action campaign
* Find the page for each creation step
* Find where to check the prerequisites before creating a campaign
* Know that sending using waves is an optional part of the scheduling step

**Glossary:**

* **Action campaign** (also called **Scheduled campaign**): Campaigns for simple ad-hoc batch communications for marketing use cases like promotional offers, engagement campaigns, announcements, legal notices, or policy updates *(product-specific)*
* **Send using waves**: Optional way to deliver the message in batches over time, offered in the scheduling step

**Guardrails:**

* Available channels vary based on your licensing model and add-ons.

* The prerequisites must be met before you start creating a campaign. They are listed in the Prerequisites section of the Get started with campaigns page.

**Terminology:**

* Canonical name: Action campaign — variants: Scheduled campaign

**FAQ:**

* **Q: What are Action campaigns used for?** — Action campaigns (or Scheduled campaigns) allow for simple ad-hoc batch communications for marketing use cases like promotional offers, engagement campaigns, announcements, legal notices, or policy updates.
* **Q: What are the steps to create an Action campaign?** — In order: define the Action campaign properties, configure the campaign action, edit the Action campaign content, define the Action campaign audience, schedule the Action campaign, then review and activate the Action campaign.
* **Q: Can I deliver the message in batches?** — Yes. When you schedule the Action campaign, you can optionally send using waves to deliver the message in batches over time.
* **Q: Which channels are supported?** — See the table in the "Channels in journeys & campaigns" section. Available channels vary based on your licensing model and add-ons.
* **Q: Where do I check the prerequisites?** — In the Prerequisites section of the Get started with campaigns page.
