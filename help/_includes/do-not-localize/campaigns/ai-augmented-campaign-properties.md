# AI Knowledge Reference

+++ AI Knowledge Reference

This section contains structured knowledge intended to support interpretation, retrieval, and question answering related to this topic.

* **TL;DR:** This page explains how to create an Action campaign of type **Scheduled - Marketing** and define its properties: name, description, tags, custom metadata fields, and access labels.

**Intents:**

* Create an Action campaign of type **Scheduled - Marketing**
* Enter a name and a description for the campaign
* Assign Adobe Experience Platform Unified Tags to classify the campaign and improve search from the campaigns list
* Fill in custom metadata fields to track business information
* Limit access to the campaign based on access labels

**Glossary:**

* **Tags**: Adobe Experience Platform Unified Tags assigned to a campaign to classify it and improve search from the campaigns list. *(product-specific)*
* **Metadata fields**: Custom fields, when defined and selected for Action campaigns, displayed in the **Properties** tab to track business information such as line of business, product or cost center. *(product-specific)*
* **Access labels**: Labels used to limit access to the campaign, set with the **Manage access** button. *(product-specific)*

**Guardrails:**

* Metadata fields marked with an asterisk are required.
* When adding an access limitation, select only labels you have permission for.

**Prerequisites and permissions:**

* Custom metadata fields on Action campaigns are available in Limited Availability; contact your Adobe representative to gain access.

**Terminology:**

* Canonical name: Action campaign properties — variants: campaign properties
* Acronym: OLAC — Object level access control

**FAQ:**

* **Q: Which campaign type do I select to create an Action campaign?** — Browse to the **Campaigns** menu, select the **Action** tab, click **Create campaign**, and select the **Scheduled - Marketing** campaign type.
* **Q: Why do I not see the Metadata fields section?** — The section is displayed if custom metadata fields have been defined and selected for Action campaigns. This capability is available in Limited Availability.
* **Q: How do I limit access to a campaign?** — Use access labels with the **Manage access** button; select only labels you have permission for.
* **Q: What are tags used for?** — To classify campaigns and improve search from the campaigns list.
