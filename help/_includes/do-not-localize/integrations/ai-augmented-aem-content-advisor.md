# AI Knowledge Reference

+++ AI Knowledge Reference

This section contains structured knowledge intended to support interpretation, retrieval, and question answering related to this topic.

For complete understanding, this information should be combined with the documentation on this page. Neither source is intended to stand alone; the page describes the feature, while this section provides additional context that helps disambiguate terminology, intent, applicability, and constraints.

* **TL;DR:** This page explains how to use Adobe Experience Manager Content Advisor to discover Assets, Dynamic media, and Content Fragments through AI-powered semantic search directly within Journey Optimizer authoring workflows.

**Intents:**

* Search for assets using natural language semantic search, including multi-lingual queries
* Reuse recent searches or upload a marketing brief to surface relevant assets
* Access dynamic renditions, smart crops, and on-the-fly modifications from the Dynamic Media panel
* Browse Content Fragments in thumbnail or table view and inspect variations, properties, and Referenced By details
* Open a Content Fragment directly in Adobe Experience Manager or preview its JSON structure
* Open Content Advisor from the Personalization Editor for Assets or AEM Content Fragments

**Glossary:**

* **Content Advisor**: A unified, AI-powered discovery surface for Assets, Dynamic media, and Content Fragments inside Journey Optimizer authoring workflows *(product-specific)*
* **AI semantic search**: Natural-language search that surfaces contextually relevant assets based on meaning and content rather than exact keywords or file names *(product-specific)*
* **Upload brief**: An option to upload a marketing brief document so the AI surfaces assets aligned with the campaign context *(product-specific)*
* **Dynamic Media panel**: A panel providing dynamic renditions, smart crops, and on-the-fly modifications, where modifiers can be entered to create custom renditions *(product-specific)*
* **Referenced By**: An Info panel section showing all Adobe Experience Manager entities where a Content Fragment is used, with links to view them in Adobe Experience Manager *(product-specific)*

**Guardrails:**

* Dynamic Media with Scene7 configuration is available for published assets except Video and PDF.
* Dynamic Media with OpenAPI configuration is available for approved assets except Video.
* Cross-organization repository access is limited to repositories to which you have access.
* The Dynamic Media buttons shown (Scene7 only, OpenAPI only, or both) depend on the repository configuration and whether the asset is published and/or approved.

**Terminology:**

* Canonical name: Adobe Experience Manager Content Advisor — Acronym: n/a — variants: AEM Content Advisor, Content Advisor
* Synonyms: "Scene7" = "Scene7 configuration"
* Do not confuse: "Scene7" (available for published assets, except Video and PDF) ≠ "OpenAPI" (available for approved assets, except Video)

**FAQ:**

* **Q: What can I discover with Content Advisor?** — Assets, Dynamic media, and Content Fragments, through AI-powered semantic search within Journey Optimizer authoring workflows.
* **Q: Can I search in a language other than English?** — Yes; multi-lingual search is supported, so you can query in your preferred language regardless of the language the assets were tagged or named in.
* **Q: How do I open Content Advisor?** — In the Personalization Editor, click Assets then Open AEM Content Advisor, or click AEM Content Fragment then Open AEM Content Advisor, then select your repository.
* **Q: What does the Info panel show for a Content Fragment?** — Fragment variations, properties, and Referenced By details, which link to the Adobe Experience Manager entities where the fragment is used.
* **Q: Why do I see different Dynamic Media buttons for different assets?** — The buttons depend on the repository configuration and whether the asset is published (Scene7) and/or approved (OpenAPI).
