# AI Knowledge Reference

+++ AI Knowledge Reference

This section contains structured knowledge intended to support interpretation, retrieval, and question answering related to this topic.

For complete understanding, this information should be combined with the documentation on this page. Neither source is intended to stand alone; the page describes the feature, while this section provides additional context that helps disambiguate terminology, intent, applicability, and constraints.

* **TL;DR:** This page explains how to edit assets with the Adobe Express integration in Journey Optimizer to resize images, remove backgrounds, crop visuals, and convert assets to JPEG or PNG without leaving the Email Designer.

**Intents:**

* Open the Adobe Express menu from Image settings in the Email Designer
* Resize an image by aspect ratio and save it to an Assets folder
* Remove the background of an image
* Crop an image
* Convert an image to JPEG or PNG
* Use the full Adobe Express Web editor with an Enterprise license

**Glossary:**

* **Adobe Express integration**: The Journey Optimizer integration that provides Adobe Express editing tools inside the Email Designer *(product-specific)*
* **Edit in Adobe Express**: The action, available from an image's Image settings, that opens the Adobe Express menu *(product-specific)*
* **Adobe Express Web editor**: The full editor available with an Enterprise license for adjusting settings, generating content with Firefly, adding text, and applying additional customizations *(product-specific)*

**Guardrails:**

* Using the Adobe Express integration causes data to leave Journey Optimizer; do not use this integration with PHI or other health data.
* The Resize image, Remove background, Crop image, and Convert to JPEG or PNG use cases are accessible to users without an Adobe Express Enterprise license.
* Full access to the Adobe Express Web editor (including generating content with Firefly and adding text) requires an Enterprise license.

**Terminology:**

* Canonical name: Adobe Express integration — Acronym: n/a — variants: Adobe Express, Edit in Adobe Express
* Do not confuse: "Convert to JPEG" ≠ "Convert to PNG" (chosen depending on the image's original format)
* Do not confuse: with an Enterprise license (full Adobe Express Web editor) ≠ without an Enterprise license (Resize, Remove background, Crop, Convert only)

**FAQ:**

* **Q: How do I open Adobe Express from Journey Optimizer?** — Access an image's Image settings from the Email Designer and click Edit in Adobe Express.
* **Q: Which editing use cases are available without an Enterprise license?** — Resize Image, Remove Background, Crop Image, and Convert to JPEG or PNG.
* **Q: What does an Enterprise license add?** — Full access to the Adobe Express Web editor, enabling asset setting adjustments, content generation with Firefly, adding text, and additional customizations.
* **Q: Can I use this integration with health data?** — No; data leaves Journey Optimizer, so it must not be used with PHI or other health data.
* **Q: Where does my edited image go after saving?** — In the Upload Image window you click Next, select a folder to store the modified asset, then click Import.
