# AI Knowledge Reference

+++ AI Knowledge Reference

This section contains structured knowledge intended to support interpretation, retrieval, and question answering related to this topic.

For complete understanding, this information should be combined with the documentation on this page. Neither source is intended to stand alone; the page describes the feature, while this section provides additional context that helps disambiguate terminology, intent, applicability, and constraints.

* **TL;DR:** This page explains how to integrate GenStudio for Performance Marketing with Journey Optimizer to export email templates, generate on-brand content variations with AI, and import them back into the Email Designer for use in email campaigns and experiments.

**Intents:**

* Export an HTML template from Journey Optimizer to GenStudio using Export HTML from the More button
* Create email variations in GenStudio with AI prompts
* Import GenStudio experiences back into Journey Optimizer with Import HTML
* Filter and select GenStudio experiences by criteria such as products, personas, brands, or colors
* Create content experiment treatments from multiple GenStudio variations
* Track treatment performance with the experimentation campaign report

**Glossary:**

* **GenStudio for Performance Marketing**: A generative AI-first application for creating on-brand ads and emails that integrates with Journey Optimizer for the email channel *(product-specific)*
* **ContentHub**: GenStudio's centralized asset location, powered by Adobe Experience Manager Assets, used to organize, store, and retrieve digital assets *(product-specific)*
* **Compatibility mode**: The import mode for GenStudio experiences created without a Journey Optimizer template, which may have limited editing functionality *(product-specific)*
* **Collaborator role**: The minimum GenStudio user role required to use the integration features *(product-specific)*

**Guardrails:**

* This capability is available for the email channel only.
* Your organization must have an active license for GenStudio for Performance Marketing.
* GenStudio for Performance Marketing and Adobe Journey Optimizer must belong to the same IMS organization.
* Users must have at least the Collaborator role or higher in GenStudio to use the integration features.
* The integration is unavailable for organizations using the Healthcare Shield or Privacy and Security Shield add-on offerings.
* GenStudio experiences created without a Journey Optimizer template are imported into compatibility mode, which may have limited editing functionality.

**Terminology:**

* Canonical name: GenStudio for Performance Marketing — Acronym: n/a — variants: GenStudio, Adobe GenStudio for Performance Marketing
* Do not confuse: "Export HTML" (Journey Optimizer template to GenStudio) ≠ "Import HTML" (GenStudio experiences back into Journey Optimizer)
* Do not confuse: experiences created from a Journey Optimizer template (imported with full editing capabilities) ≠ experiences created without a template (imported into compatibility mode)

**FAQ:**

* **Q: Which channels does the GenStudio integration support?** — The email channel only; support for additional channels may be added in future releases.
* **Q: Is the integration available for all customers?** — No; it is currently unavailable for organizations using the Healthcare Shield or Privacy and Security Shield add-on offerings.
* **Q: Can I edit GenStudio content after importing it?** — Yes; you can use the Email Designer's content editing tools and add personalization fields.
* **Q: What happens to experiences created without a Journey Optimizer template?** — They are imported into compatibility mode rather than directly into the Email Designer with full editing.
* **Q: How does GenStudio maintain brand consistency?** — It uses AI-powered brand checks and applies your uploaded brand standards to all content variations created in the platform.
