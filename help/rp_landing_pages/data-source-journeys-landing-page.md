# Data source configuration{#section-overview}

Data sources in Adobe Journey Optimizer allow you to connect to systems that enrich your journeys with real-time, personalized data- whether from Adobe’s built-in platform or external systems you configure. By setting up these connections, you can tailor your journeys with dynamic conditions, personalized messages, and more. This section explores the different types of data sources (pre-configured and external), how to manage the fields you need through field groups, and the steps to set up and customize these integrations. With clear guidance and examples, you’ll learn to unlock the power of data to create smarter, more impactful customer experiences.
