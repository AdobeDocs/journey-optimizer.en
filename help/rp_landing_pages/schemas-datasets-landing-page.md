# Manage relational Schemas and Datasets{#section-overview}

Managing relational schemas and datasets in Adobe Journey Optimizer helps you structure and organize your data for impactful, personalized campaigns. Whether you're defining data relationships manually or using DDL files, these schemas lay the foundation for connecting customer records and campaign data seamlessly. You'll also learn how to create datasets and ingest data from various sources to ensure it’s ready for real-time orchestration and targeting. Each topic - from schema creation to linking and data ingestion - guides you step-by-step, empowering you to confidently transform raw data into actionable insights and deliver exceptional customer experiences.
