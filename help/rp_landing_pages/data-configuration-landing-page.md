# Data configuration{#section-overview}

Data configuration in Adobe Journey Optimizer is all about setting up the foundation for effective customer journeys by organizing and connecting your data. Whether you're defining relational schemas to structure your data, linking them to customer profiles for personalization, or configuring channels for precise message delivery, this process ensures your campaigns are powered by clean, actionable insights. You'll explore how to create schemas manually or with file uploads, configure datasets, and map profiles for targeted communication. Each step builds towards enabling orchestrated, real-time customer experiences, giving you the tools to turn raw data into meaningful interactions.
