# Set message & journey capping rules{#section-overview}

Capping rules are part of [conflict management & prioritization](../using/conflict-prioritization/gs-conflict-prioritization.md) — they help ensure customers receive the right amount of communication without feeling overwhelmed. Before applying rules, use the [conflict detection tool](../using/conflict-prioritization/conflicts.md) to identify overlapping journeys and campaigns. When multiple communications qualify for the same profile, [priority scores](../using/conflict-prioritization/priority-scores.md) determine which message is delivered first.

You can set limits on how often messages are sent (frequency capping), how many journeys a profile can enter (journey capping), and when messages are blocked (quiet hours). Rules are grouped into **rule sets** and applied to campaigns or journeys. For programmatic control from external systems, see the [Capping API](../using/configuration/capping.md).
