# Guided channel setup{#section-overview}

Guided Channel Setup in Adobe Journey Optimizer simplifies the process of configuring mobile and web marketing channels, helping you get campaigns up and running quickly and effectively. Whether you're setting up iOS, Android, or web platforms, this tool automatically creates key resources like mobile tag properties and datastreams, so you can focus on delivering impactful customer experiences. You'll explore prerequisites to ensure you're ready, learn about the resources generated for you, and see how each channel configuration works. By the end, you’ll have a clear, actionable roadmap to connect your marketing goals to the right channels with confidence.
