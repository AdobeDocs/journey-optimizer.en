# API reference{#section-overview}

Adobe Journey Optimizer's Code-Based Experience channel empowers you to deliver personalized offers across your digital touchpoints with flexibility and precision. Whether you're working with client-side tools like the AEP Web or Mobile SDKs, server-side integrations via the AEP Edge Network API, or a hybrid approach, this feature adapts to your needs. Each implementation method offers unique benefits, from real-time interactions to scalable back-end processing. In the sections ahead, you'll discover the fundamentals of Experience Decisioning, learn how to choose and implement the right method for your use case, and access resources to streamline your journey. Let’s unlock new possibilities for tailored customer experiences.
