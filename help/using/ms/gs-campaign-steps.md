# Steps to create orchestrated campaigns {#ms-campaign-steps}


* Access Orchestrated Campaigns, explore your campaigns list, add tags, discover quick actions. Learn more
* Create/extend schemas, setup datasets, configure data ingestion

* Build segments from ingested data
* Use canvas activities
* Validate your Orchestrated Campaign lifecycle

* Send messages - Email & SMS
* Use enrichment-based personalization
* Review Reporting dashboards

* Test direct personalization without Enrichment activity
* Retargeting on feedback events
* Build journeys using Email & SMS (soon Push notifications)

* Validate multi-entity relationships in segmentation, personalization & reporting
