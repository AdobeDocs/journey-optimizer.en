# Content Credentials in AI Assistant {#generative-content-credentials}

>[!BEGINSHADEBOX]

**On this page:** Learn which AI Assistant actions attach Content Credentials, what this means for images that combine several generative AI sources, and what carries over when your content moves between apps.

>[!ENDSHADEBOX]

>[!INFO]
>
>New laws are emerging around generative AI transparency, and Adobe is working to meet applicable requirements across jurisdictions. Content Credentials are the provenance tool Adobe uses to meet the requirements of these laws.

Content Credentials are durable, invisible metadata that record how a piece of content was created or edited. When you use AI Assistant in Adobe Journey Optimizer to generate or edit an image with generative AI tools, Content Credentials are automatically attached to that image, no action is required on your part.

## Which AI Assistant actions attach Content Credentials {#cc-workflows}

The following table summarizes when Content Credentials are attached, based on the image action performed in AI Assistant.

| Action | Description | Content Credentials attached? |
|---|---|---|
| **Generate an image** | Create a new image from a text prompt, from a reference image, or generate a similar image | Always. The image is generated by generative AI, so it always carries a fresh Content Credential. |
| **Crop an image** (center or smart crop) | Adjust an image to requested dimensions | Only if the source image already had a Content Credential. Cropping itself does not add a new generative AI action, it preserves the existing one. |
| **Add a text overlay** | Render generated text on top of a background image | Only if the background image already had a Content Credential. The overlay step preserves it, it does not add a new generative AI action. |
| **Overlay images** | Composite two or more images together | If any of the source images have a Content Credential, the combined image carries all of them, merged into a single Content Credential. |

>[!NOTE]
>
>Cropping or overlaying an image technically produces new pixels, which would normally erase any existing Content Credential. AI Assistant reads the Content Credential from the source image(s) before this happens, then rebuilds and re-attaches it to the result, so the record of generative AI involvement is never lost.

## Use cases you will recognize {#cc-use-cases}

* **I generated an image from a text prompt** → a Content Credential is attached.
* **I generated a similar image from a reference image** → a Content Credential is attached, since the result is a new generative AI image.
* **I cropped an image that was generated or edited with generative AI** → the Content Credential is preserved through the crop.
* **I added a text overlay on a background image that was generated with generative AI** → the Content Credential from the background image is preserved.
* **I combined several images, some generated with generative AI and some not** → the resulting image carries a Content Credential that reflects only the generative AI sources.
* **I cropped or overlaid a photo that was not generated or edited with generative AI** → no Content Credential is created, since there is no generative AI action to record.

## Combining multiple generative AI sources {#cc-multiple-sources}

When an image combines content from several generative AI sources, for example several AI-generated images composited into one, AI Assistant merges all their provenance into a single Content Credential for the resulting image. Each contributing source is recorded as an ingredient, and each generative AI action from those sources is recorded individually, so the full chain of generative AI involvement stays visible in the final image.

If you open one image that already carries a generative AI action, then add other images that together carry several more generative AI actions, the resulting Content Credential lists every one of them, alongside the images they came from.

## Content types and their scope {#cc-content-types}

* **Images**: Covered. Content Credentials are attached when images are generated with generative AI, and preserved through cropping, text overlay, and image overlay operations performed by AI Assistant.
* **Text**: Not applicable. Text-only outputs of AI Assistant, such as copy generation, translation, and brand alignment suggestions, do not require Content Credentials.

## What happens as your content moves {#cc-content-moves}

Content Credentials travel with the image file. When an image that was generated or edited with generative AI is downloaded or exported from Adobe Journey Optimizer, its Content Credentials are preserved. [Learn more about Content Credentials](https://helpx.adobe.com/firefly/using/content-credentials.html){target="_blank"}.

Some ways of bringing images into your content, such as extracting an image from a PDF or from an embedded (base64) source, may not preserve the original Content Credential. In these cases, no Content Credential can be read from the source, and none is created for the result.

Once your content leaves Adobe Journey Optimizer, whether Content Credentials remain visible depends on the third-party platform receiving it. Adobe attaches the credential; how a given third-party platform displays or handles it is outside of Adobe's control.
