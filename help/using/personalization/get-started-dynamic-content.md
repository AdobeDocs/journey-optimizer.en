# Get started with dynamic content {#start-dynamic-content}

>[!BEGINSHADEBOX]

**On this page:** Understand how dynamic content uses conditional rules built from profile attributes, contextual events, and audiences to adapt your messages to targeted profiles.

>[!ENDSHADEBOX]

>[!CONTEXTUALHELP]
>id="ajo_conditions_list"
>title="Conditions"
>abstract="Conditional rules allow you to display multiple content variants in your messages based on profile attributes, contextual events or audiences." 

Dynamic content allows you to adapt the content of your messages based on **conditional rules** that can be made up of profile attributes, contextual events or audiences. Conditional rules are created using a visual rule builder within the personalization editor, where you can store them for further reuse across your journeys and campaigns. 

Conditional rules can be leveraged into the Email Designer and the personalization editor to **create dynamic content** which will adapt to the profiles targeted in your messages.

>[!TAB Overview]

**TL;DR**

This page introduces dynamic content in Journey Optimizer — how conditional rules built from profile attributes, contextual events, and audiences allow messages to adapt to the profiles they target.

**Intents**

* Understand what dynamic content is and how it differs from static message content
* Identify the two entry points for dynamic content: the Email Designer and the personalization editor
* Navigate to the appropriate guide for building conditional rules or creating dynamic content

>[!TAB Glossary]

* **Dynamic content**: Message content that adapts based on conditional rules; different content is shown to different profiles depending on whether defined conditions are met. *(product-specific)*
* **Conditional rule**: A set of criteria — built from profile attributes, contextual events, or audiences — that determines which content variant a profile receives. *(product-specific)*
* **Visual rule builder**: The interactive canvas within the personalization editor used to create and store conditional rules. *(product-specific)*

>[!TAB Terminology]

* **Canonical name:** dynamic content — variants: conditional content, personalized content
* **Synonyms:** "conditional rules" = "conditions" (as labeled in the UI)
* **Do not confuse:** dynamic content (content that adapts per profile based on conditional rules) ≠ static content (the same content shown to all recipients regardless of conditions)

>[!TAB FAQ]

**Q: What types of criteria can conditional rules use?**

Conditional rules can be built from profile attributes, contextual events, and audience membership.

**Q: Where can conditional rules be used to create dynamic content?**

In the Email Designer (to create component variants) and in the personalization editor (to wrap expression blocks with conditions). Both entry points are covered in linked pages.

**Q: Can conditional rules be reused across journeys and campaigns?**

Yes. Conditional rules can be stored for further reuse across journeys and campaigns.
