# Troubleshoot your journey {#troubleshooting}

When a customer journey does not behave as expected, identifying the root cause can be challenging. To help you resolve issues efficiently, you can find below troubleshooting resources by the most common problem areas. Whether you see journey failures, execution inconsistencies, or action-level problems, each section provides targeted guidance to investigate and resolve them.

Explore the pages below to dive into specific troubleshooting topics:

* **[Troubleshoot journey errors](../building-journeys/troubleshooting.md)**
  Learn how to identify and resolve journey-level errors, including configuration problems and platform-level issues.

* **[Troubleshoot journey execution](../building-journeys/troubleshooting-execution.md)**
  Understand how to trace participant flow, pinpoint delays, and address unexpected execution behavior.

* **[Troubleshoot inbound actions](../building-journeys/troubleshooting-inbound.md)**
  Get help diagnosing issues with inbound events, webhooks, and triggers that initiate or update journeys.

* **[Troubleshoot a custom action](../action/troubleshoot-custom-action.md)**
  Learn how to debug and validate custom actions, including data handling, response errors, and integration failures.

Additionally, check out this [Adobe Community blog post](https://experienceleaguecommunities.adobe.com/t5/journey-optimizer-blogs/demystifying-adobe-journey-optimizer-error-codes-root-causes-and/ba-p/760884){target="_blank"} detailing **common error codes** and how to resolve them effectively.

These resources will help you quickly isolate issues, validate your setup, and get your journeys running smoothly again.
